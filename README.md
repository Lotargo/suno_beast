# Suno Beast — Chrome / Edge

Расширение записывает звук вкладки Suno, разделяет треки при автопереходе и сохраняет их с обложкой и метаданными. Интерфейс работает в обычном браузере, обработка аудио — через локальный помощник и FFmpeg.

## Что входит в проект

| Каталог | Назначение |
| --- | --- |
| `extension/` | Готовое расширение Manifest V3: панель, телеметрия Suno, запись и загрузки |
| `native/` | Node.js-помощник, обработка FFmpeg, индекс коллекции и установка Native Messaging |
| `tests/` | Локальные проверки записи, переходов, метаданных, файлов и границ доступа |
| `tools/` | Необязательные инструменты разработчика: предпросмотр и сборка иконок |

Electron, десктопное окно, preload/IPC-код и отдельный launcher удалены. Файлы расширения не требуют сборки. В основном проекте нет сторонних npm-зависимостей; `package.json` нужен для команд проверки и установки помощника.

## Установка

Для текущего варианта с обработкой MP3/WAV нужны Windows, Node.js с npm, FFmpeg и ffprobe в `PATH`.

### 1. Один раз зарегистрировать аудиопомощник

Из корня репозитория:

```powershell
npm run install:helper
```

Команда запускает `native/install.ps1`. Он создаёт `native/launch-host.cmd` и `native/com.sunobeast.audio.json` с путями этого компьютера и регистрирует Native Messaging host `com.sunobeast.audio` в HKCU для Chrome/Edge. Права администратора и постоянно работающий сетевой сервер не нужны. Эти сгенерированные файлы исключены из Git.

Этот шаг нужен именно аудиопомощнику: загрузка расширения через режим разработчика не регистрирует Node.js/FFmpeg в системе. Без помощника сведения о треке доступны, но обработка и сохранение аудио в текущем варианте не работают. Основание: [Chrome — Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging).

### 2. Загрузить расширение

1. Открой `chrome://extensions` или `edge://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери **папку `extension`**, где находится `manifest.json`. В этой рабочей копии: `F:\projects\suno-beast\extension`.
4. Закрепи кнопку Suno Beast в панели браузера и открой Suno.
5. Нажми кнопку расширения, чтобы открыть панель поверх страницы.

Запускать приложение, `npm start` или bat-файл не требуется. Вход Google выполняется на сайте в обычном Chrome/Edge; перенос cookies и паролей не нужен.

### Обновление, перенос и удаление

После изменения файлов нажми «Обновить» на карточке расширения и снова открой панель в Suno. Обновляй расширение после окончания записи: перезапуск его контекста прерывает захват. Страница Suno подключается повторно автоматически, без F5. Auto-Grab после перезапуска нужно включить снова.

Копирование проекта не переносит путь загруженного расширения и регистрацию помощника. Если уже зарегистрирован помощник из другой папки, установщик остановится с `A different host is already registered`. Старую рабочую копию нужно сохранять до отдельного переноса подключения. Чистка репозитория сама по себе регистрацию не меняет.

Для удаления регистрации текущей копии:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\native\uninstall.ps1
```

Удаляется только принадлежащая этой копии регистрация помощника; записи, коллекция и профиль браузера сохраняются. Само расширение удаляется на странице управления расширениями.

## Запись

- **Записать / Остановить** — ручная запись вкладки. Явная остановка кнопкой сохраняет намеренный фрагмент.
- **Auto-Grab** — запись полных треков от начала до естественного конца. Автопереход запускает захват следующего трека сразу, пока предыдущий обрабатывается отдельно.
- Пауза в Suno дольше 1,2 секунды, перемотка и переключение незавершённого трека отбрасывают обрывок без готового файла. Продолжение с середины пропускается до следующего старта с начала.
- **Сохранить MP3** — прямое сохранение найденного HTTPS-потока Suno. При `blob:` без обнаруженного CDN-адреса доступна запись вкладки. Служебный `sil-100.mp3` игнорируется.
- Закрытие панели не останавливает запись. Закрытие вкладки или уход с Suno выключает захват.

Захватывается весь звук вкладки. Запись проходит через WebM Opus и затем MP3/WAV; WAV не восстанавливает качество оригинала. При прямом MP3 и отключённой обрезке аудиопакеты копируются без перекодирования. Лимит исходной записи и очереди — 256 МБ; передача готового файла в браузер ограничена 512 МБ.

## Панель и метаданные

Карточка показывает настоящую обложку, название, исполнителя, модель, доступный альбом и время воспроизведения. Индикатор времени не позволяет перематывать. Пустые данные не подменяются выдуманными.

«Стиль и текст» раскрывает сведения из публичной карточки точного ID песни. Запрос не скачивает аудио, не читает cookies и не исполняет скрипты Suno. Данные кешируются на 15 минут; «Обновить сведения» повторяет запрос. Отсутствие обложки или закрытая карточка не должны терять аудио.

В MP3 встраиваются обложка, стиль, текст, альбом, модель и ссылка на источник; для WAV сохраняются поддерживаемые текстовые поля без встроенной обложки. Старые записи автоматически не переписываются.

Панель имеет переключатель RU / EN с сохранением выбора. Названия, тексты песен и пути остаются исходными. Шапка использует извлечённый логотип Suno с меткой Beast; собственная иконка используется для кнопки расширения. Источники ресурсов указаны в `extension/assets/README.md`.

## Настройки и коллекция

Форматы: MP3 320 кбит/с или WAV 24 бит. Можно включить обрезку тишины по краям и выбрать порог от −60 до −20 dB; паузы внутри трека сохраняются.

По умолчанию готовые файлы сохраняются в стандартные загрузки браузера. Кнопка «Выбрать папку…» включает сохранение помощником в указанную папку; «По умолчанию» возвращает загрузки браузера. Смена папки доступна после завершения записи и сохранения. Старые файлы не перемещаются.

Дубли определяются по точному ID Suno, а не по названию. Auto-Grab пропускает уже сохранённый полный трек. Разные генерации с одним названием остаются разными записями. Ручной фрагмент не блокирует последующую полную запись. Удалённый или изменённый файл можно записать заново.

Старую запись без ID можно связать с текущим треком кнопкой «Связать с существующим файлом…». Выбирай полный MP3/WAV именно этой генерации; помощник проверяет наличие аудио, не переписывая файл.

Настройки и индекс коллекции находятся в `%LOCALAPPDATA%\SunoBeast`. В режиме загрузок браузера запись попадает в коллекцию после завершения загрузки и проверки содержимого. При отмене готовый файл остаётся в `SunoBeast\pending`, путь показывается в сообщении.

При ошибке FFmpeg исходник сохраняется как `Recovery_*.webm` в выбранной папке или `%LOCALAPPDATA%\SunoBeast\recovery`. При потере связи с помощником расширение пытается сохранить резервный WebM в загрузках браузера, подкаталог `Suno Beast`. Данные активной записи в памяти могут быть потеряны при закрытии браузера.

## Доступы

Скрипт содержимого работает только в `https://suno.com` и `https://www.suno.com`. Дополнительные домены Suno CDN используются для обнаружения и чтения аудио/обложек. Доступа к Google, cookies, истории и паролям нет.

`tabCapture` получает звук вкладки после действия пользователя. `scripting` восстанавливает связь только с проверенной вкладкой Suno. `offscreen` сохраняет захват при закрытии панели. `nativeMessaging` передаёт аудио локальному помощнику; `downloads` доставляет готовые файлы браузеру; `storage` хранит настройки. User-Agent, TLS и защита Google не меняются.

Плавающая панель изолирована iframe с origin расширения и закрытым Shadow DOM. Команды принимаются только от зарегистрированной сессии панели, привязанной к вкладке, frame и document. Помощник допускает единственный ID `pkcnkgcepdcheeadhfhbddncimmndmlf`, проверяет команды и лимиты; загрузчики проверяют каждый redirect Suno CDN. FFmpeg читает исходники только через локальные протоколы `file,pipe`.

## Разработка и проверки

```powershell
npm test
```

Для тестов нужны Node.js, FFmpeg и ffprobe. Установка npm-пакетов для них не требуется. Проверки охватывают переходы рекордера, задержки onstop/FFmpeg, незавершённые треки, дубли, Native Messaging, обработку аудио, теги и обложки, загрузки браузера, метаданные, RU/EN и границы доступа. Тест сгенерированного Windows-лаунчера пропускается, если он ещё не создан установщиком.

Локальные тесты моделируют API Chrome. Для проверки установленной версии обнови расширение, включи Auto-Grab до начала трека, дождись завершения двух треков, а третий прерви в Suno. Первые два должны сохраниться целиком, третий — отсутствовать в загрузках. Системные диалоги и доставку в реальные загрузки проверяй в установленном расширении.

Необязательный предпросмотр интерфейса на демонстрационных данных:

```powershell
node tools/preview-popup.js
```

Открой `http://127.0.0.1:18889/popup.html` или `/floating-preview.html`. Предпросмотр не записывает звук и не подключает помощник.

`tools/render-icons.js` пересобирает PNG из SVG. Только этому инструменту нужен внешний модуль `sharp` — его можно указать через `SUNO_BEAST_SHARP`. Для использования расширения, помощника и тестов он не нужен: готовые иконки включены в Git.

`.gitignore` исключает зависимости, личные записи, временные данные, ключи, сгенерированные файлы помощника и предпросмотры `design/`. Небольшие намеренные аудиофикстуры можно хранить в `tests/fixtures/`. Исходники имеют LF, Windows-скрипты — CRLF согласно `.gitattributes`.
