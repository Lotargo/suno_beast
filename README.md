## Возможности

Suno Beast добавляет к Suno компактную панель записи. Браузер захватывает звук вкладки, а локальный помощник с FFmpeg обрабатывает его и сохраняет готовые файлы.

| | Что умеет расширение |
| :--- | :--- |
| **Auto-Grab** | Записывает полные треки и разделяет их при автопереходе. Уже сохранённые генерации пропускает. |
| **Ручная запись** | Позволяет сохранить выбранный фрагмент кнопками «Записать» / «Остановить». |
| **MP3 и WAV** | MP3 320 кбит/с, WAV 24 бит, обрезка тишины по краям. Прямое сохранение MP3 доступно при обнаружении потока. |
| **Карточка трека** | Обложка, название, исполнитель, доступный альбом, модель и время. Индикатор прогресса без перемотки. |
| **Метаданные** | Стиль и текст из карточки Suno; теги и обложка в MP3, поддерживаемые текстовые поля в WAV. |
| **Своя коллекция** | Проверка дублей по ID Suno и привязка уже существующего файла к треку. |
| **Удобное сохранение** | Стандартные загрузки браузера или выбранная папка. Интерфейс на русском и английском. |

## Совместимость

**Chrome и Edge поддерживаются на Windows и macOS, Яндекс Браузер — на Windows.** Linux не поддерживается.

| Браузер | Статус |
| :--- | :--- |
| Chrome, Edge | Поддерживаются на Windows и macOS. |
| Opera, Opera GX | Экспериментальная совместимость: тот же пакет расширения, регистрация помощника через Chrome. Нужна проверка реальной записи в каждом браузере. |
| Яндекс Браузер | Поддерживается на Windows. На macOS — экспериментально: регистрация помощника добавлена, проверка на Mac ещё нужна. |
| Firefox, Safari | Пока не поддерживаются; требуют отдельного переноса механизма записи и связи с помощником. |

Наличие Chromium в основе браузера само по себе не гарантирует работу записи. Нужны API захвата звука вкладки и фонового документа; при их отсутствии расширение покажет понятную ошибку. Подробности и порядок проверки — в [матрице совместимости](docs/BROWSER_COMPATIBILITY.md).

Требования к браузеру:

- **Chrome или Edge 116+** либо актуальный Яндекс Браузер на Windows. Opera, Opera GX и Яндекс Браузер на macOS доступны для экспериментальной проверки. Оформление списка форматов поддерживается начиная с Chromium 135.

При установке из исходников также нужны:

- **[Node.js](https://nodejs.org/en/download)** с npm.
- **[FFmpeg и ffprobe](https://ffmpeg.org/download.html)**, доступные в `PATH`.

## Установка

### Готовый установщик для Windows

Скачай [**Suno-Beast-v2.11.0-Windows-x64-Setup.exe**](https://github.com/Lotargo/suno_beast/releases/download/v2.11.0/Suno-Beast-v2.11.0-Windows-x64-Setup.exe). Установщик содержит всё необходимое: отдельно устанавливать Node.js, npm, FFmpeg и ffprobe не нужно.

1. Запусти установщик и выбери папку программы. Установка выполняется для текущего пользователя.
2. После завершения открой предложенную инструкцию и загрузи папку `extension` в браузер через режим разработчика.
3. Закрепи кнопку Suno Beast и открой Suno.

Папка программы по умолчанию — `%LOCALAPPDATA%\Programs\SunoBeast`. Инструкция также доступна в меню «Пуск» → Suno Beast. При обновлении заверши запись и закрой браузеры с Suno Beast, затем запусти новый установщик в ту же папку. После запуска браузера перезагрузи расширение. Удаление программы сохраняет записи, настройки и коллекцию.

Если помощник уже подключён из другой папки, установщик сам переключит браузеры на новую копию после проверки компонентов. Старые файлы и записи сохранятся. При удалении программы прежняя регистрация восстановится, если её файл ещё существует; более поздние изменения регистрации сохранятся.

### Установка из исходников: Windows и macOS

Следующие шаги нужны для исходного архива и Git-копии проекта.

### 1. Скачать проект

Скачай [**Suno-Beast-v2.11.0.zip**](https://github.com/Lotargo/suno_beast/releases/download/v2.11.0/Suno-Beast-v2.11.0.zip) на [странице последнего релиза](https://github.com/Lotargo/suno_beast/releases/latest) и распакуй его в постоянную папку. Исходники также доступны через **Code → Download ZIP** на [странице репозитория](https://github.com/Lotargo/suno_beast). Или используй Git:

```powershell
git clone https://github.com/Lotargo/suno_beast.git
cd suno_beast
```

Сборка расширения и `npm install` не требуются.

### 2. Подключить аудиопомощник

Открой терминал в корне распакованного проекта (PowerShell на Windows). Проверь, что установленные инструменты доступны:

```sh
node --version
npm --version
ffmpeg -version
ffprobe -version
```

Затем выполни:

```sh
npm run install:helper
```

Команда определяет платформу и регистрирует локальный аудиопомощник для Chrome и Edge, а на macOS — также для Яндекс Браузера. Opera, Opera GX и Яндекс Браузер на Windows используют регистрацию Chrome — устанавливать сам Chrome для этого не нужно. На macOS манифесты находятся в `~/Library/Application Support/Google/Chrome/NativeMessagingHosts`, `~/Library/Application Support/Microsoft Edge/NativeMessagingHosts` и `~/Library/Application Support/Yandex/YandexBrowser/NativeMessagingHosts`. Права администратора не нужны. Помощник запускается браузером по необходимости через [Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging). После установки перезапусти браузер.

### 3. Загрузить расширение в браузер

1. Открой `chrome://extensions` в Chrome, `edge://extensions` в Edge, `opera://extensions` в Opera / Opera GX или `browser://extensions` в Яндекс Браузере.
2. Включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение**.
4. Выбери **папку `extension` внутри проекта** — в ней находится `manifest.json`.
5. Закрепи Suno Beast в панели браузера через меню расширений.
6. Открой [suno.com](https://suno.com), войди в аккаунт обычным способом и нажми кнопку Suno Beast.

Оставь папку проекта на месте: браузер и аудиопомощник используют файлы из неё.

## Как пользоваться

### Записать несколько треков

Включи **Auto-Grab до начала воспроизведения**, затем запусти трек с начала в Suno. Расширение сохранит его после естественного завершения и продолжит запись следующего. Обработка предыдущего файла идёт отдельно.

Если включить Auto-Grab посреди песни, он дождётся следующего старта с начала. Пауза в Suno дольше 1,2 секунды, перемотка или переключение незавершённого трека отменяют текущий фрагмент — обрывок не попадает в готовую коллекцию.

### Сохранить фрагмент или прямой MP3

- **Записать → Остановить** — ручная запись; остановка кнопкой расширения сохраняет выбранный фрагмент.
- **Сохранить MP3** — сохранение обнаруженного прямого аудиопотока. Кнопка становится доступна, когда найден подходящий адрес и нет активной записи.

Закрытие панели не останавливает запись. Закрытие вкладки или уход с Suno прекращает захват.

### Выбрать формат и папку

Открой **Настройки записи**: выбери MP3 или WAV, обрезку тишины и порог. По умолчанию файлы отправляются в **стандартные загрузки браузера**. **Выбрать папку…** включает сохранение в другую папку; **По умолчанию** возвращает загрузки браузера.

Папку меняй после окончания записи и обработки. Ранее сохранённые файлы остаются на своих местах.

### Обложки, текст и дубли

**Стиль и текст** раскрывает сведения о текущей песне. В MP3 сохраняются доступные обложка, текст, стиль, альбом, модель и ссылка на источник. В WAV — поддерживаемые текстовые поля без встроенной обложки.

Auto-Grab проверяет коллекцию по **точному ID Suno**: одинаковые названия у разных генераций не мешают записи. Ручной фрагмент не блокирует последующую полную запись. Старый полный файл можно добавить в коллекцию через **Связать с существующим файлом…** — файл не переписывается.

Запись захватывает весь звук вкладки и проходит через WebM Opus с последующим преобразованием. Выбор WAV не повышает качество исходного звука. Прямой MP3 при отключённой обрезке сохраняется без перекодирования.

## Вопросы и решения

| Ситуация | Что сделать |
| :--- | :--- |
| Помощник не подключён | Проверь Node.js, FFmpeg и ffprobe в `PATH`, выполни `npm run install:helper` из папки проекта и перезапусти браузер. |
| PowerShell блокирует `npm.ps1` | Используй `npm.cmd run install:helper`. |
| Установка помощника из исходников пишет `A different host is already registered` или `a different host is already registered` | Зарегистрирована другая копия. На Windows запусти `native/uninstall.ps1` из старой папки; на macOS удали регистрацию из папки `NativeMessagingHosts` соответствующего браузера, затем установи помощник из новой папки. Готовый Windows-установщик переключает регистрацию автоматически. |
| После обновления видно старое поведение | На странице расширений нажми кнопку перезагрузки карточки Suno Beast, затем снова открой панель. |
| MP3-кнопка недоступна | Прямой поток ещё не обнаружен. Используй запись вкладки. |
| Auto-Grab пропускает текущую песню | Проверь, что трек запущен с начала и его полная запись ещё не существует в коллекции. |
| Загрузка отменена | Готовый файл остаётся в `%LOCALAPPDATA%\SunoBeast\pending` (Windows) или `~/Library/Application Support/SunoBeast/pending` (macOS); путь отображается в панели. |

**Обновление.** Закончи запись, обнови файлы проекта в прежней папке, выполни `npm run install:helper` и перезагрузи расширение на странице управления. При первом подключении помощника перезапусти браузер. После перезапуска включи Auto-Grab заново. Изменения версий перечислены в [changelog](CHANGELOG.md).

**Удаление.** Удали расширение в браузере. На Windows для удаления регистрации аудиопомощника выполни из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\native\uninstall.ps1
```

На macOS удали `com.sunobeast.audio.json` из папок `NativeMessagingHosts`, указанных выше. Записи и настройки сохраняются. Настройки и индекс коллекции находятся в `%LOCALAPPDATA%\SunoBeast` (Windows) или `~/Library/Application Support/SunoBeast` (macOS).

## Локальная обработка

Аудио обрабатывается на компьютере через FFmpeg. Расширение работает на страницах Suno и использует его CDN для аудио и обложек. Метаданные читаются из публичной карточки песни; доступа к паролям, cookies и истории браузера нет.

Пользователь самостоятельно несёт ответственность за использование расширения.
