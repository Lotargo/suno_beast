# Suno Beast — Chrome / Edge

Suno работает в обычном Chrome или Edge, расширение записывает звук вкладки, а локальный помощник сохраняет и обрабатывает аудио через FFmpeg.

Google ограничивает OAuth во встроенных WebView. Подмена Electron под Firefox удалена: она не делает встроенный браузер поддерживаемым. Вход выполняется на сайте в полноценном браузере с его существующим профилем. Пароли и cookies не переносятся в Electron или помощник.

## Установка

Нужны Windows, Node.js с npm, а также FFmpeg и ffprobe в `PATH`.

В каталоге репозитория:

```powershell
npm ci
npm run install:helper
```

Установщик создаёт `native/launch-host.cmd` и `native/com.sunobeast.audio.json` с путями этого компьютера и регистрирует помощник для Chrome/Edge в HKCU. Эти сгенерированные файлы не хранятся в Git.

Затем загрузи расширение:

1. В адресной строке Chrome открой `chrome://extensions` (для Edge — `edge://extensions`).
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери папку `extension` внутри репозитория (в текущей рабочей копии — `F:\projects\suno-beast\extension`).
4. При желании закрепи **Suno Beast** в панели браузера.
5. Открой панель расширения во вкладке Suno — скрипт подключится автоматически, в том числе в уже открытой странице.
6. При подключённом помощнике доступны кнопки записи. В ожидании отдельная строка «Готов к записи» не отображается.

Если в Chrome ты уже вошёл в Suno, можно использовать существующую сессию. Переносить cookies не нужно. Инструмент автоматизации не имеет доступа к `chrome://extensions`, поэтому загрузка выполняется вручную.

**После перемещения проекта:** копирование каталога не меняет путь уже загруженного расширения и регистрацию Native Messaging. Если зарегистрирован помощник из другой папки, установщик остановится с сообщением `A different host is already registered`; такую регистрацию нужно переносить отдельно. Не удаляй старую рабочую копию до переноса подключения.

## Файлы репозитория

В Git включаются исходники `extension/`, `native/`, `src/`, `scripts/`, `tests/`, ресурсы иконок и `package-lock.json`. `.gitignore` исключает зависимости, записи, временные данные, приватные ключи, сгенерированные настройки помощника и скриншоты из `design/`. Небольшие намеренные аудиофикстуры можно хранить в `tests/fixtures/`. `.gitattributes` задаёт LF для исходников и CRLF для Windows-скриптов.

`npm test` запускает локальные проверки. Тест установленного Windows-лаунчера пропускается, если `native/launch-host.cmd` ещё не создан установщиком; остальные тесты помощника запускают Node напрямую. Для аудиопроверок нужны FFmpeg и ffprobe.

Ошибка `Extension context invalidated` означает, что Chrome отключил контекст старого скрипта после обновления расширения. С 2.4.1 такой скрипт перехватывает и синхронную ошибку отправки, и отклонённый Promise, снимает обработчики и останавливает таймер. Временная недоступность получателя повторяется без отключения исправного скрипта. Уже появившиеся записи в журнале Chrome автоматически не удаляются.

**Версия 2.4.2 восстанавливает подключение к уже открытой странице.** После обновления расширения открой его панель в Suno: она проверит ответ скрипта и при необходимости подключит актуальные `policy.js`/`content.js` через штатный `chrome.scripting`, без F5 и остановки музыки. Проверка выполняется также перед записью; при отказе доступа режим не включается молча, а показывает ошибку связи. Восстановление разрешено только в основном фрейме `https://suno.com` и `https://www.suno.com`, в изолированном контексте. Повторное подключение не дублирует таймеры/обработчики. После перезапуска расширения Auto-Grab нужно включить снова; уже звучащий с середины трек пропускается до следующего старта с начала.

## Запись

- **Записать** — начинает ручную запись звука вкладки Suno. Повторное нажатие останавливает её и сохраняет результат. Закрытие панели не останавливает запись.
- **Auto-Grab** — после нажатия разрешает захват текущей вкладки. Сохраняются треки, записанные с начала до естественного конца. При автопереходе Suno новая запись запускается сразу: обработка предыдущего трека идёт в отдельной очереди. Пауза дольше 1,2 секунды, перемотка, переключение незавершённого трека и выключение Auto-Grab отбрасывают обрывок без MP3/WAV или Recovery-файла. Возобновлённый с середины трек пропускается до следующего воспроизведения с начала. После закрытия вкладки или ухода с Suno режим выключается.
- **Сохранить MP3 из потока** — доступно после обнаружения поддерживаемого CDN-адреса. Если Suno использует `blob:` и ссылка CDN не обнаружена, пользуйся записью вкладки. Служебный файл тишины `sil-100.mp3` игнорируется.
- **Настройки записи** — MP3 320 кбит/с или WAV 24 бит; порог тишины от −60 до −20 dB; обрезка начала и конца. Паузы внутри трека сохраняются.
- **Папка записей** — открывает каталог с результатами.

## Коллекция и папка сохранения — версия 2.3.0

По умолчанию готовые MP3/WAV поступают в **стандартную папку загрузок Chrome/Edge** через API загрузок браузера. Учитывается папка, выбранная в настройках самого браузера; файлы больше не направляются в каталог проекта. Если в браузере включён запрос места сохранения для каждой загрузки, он может показать свой диалог. Кнопка «Мои записи» открывает соответствующую папку.

В «Настройках записи» → «Папка сохранения» кнопка **«Выбрать папку…»** открывает системный диалог. В выбранную папку помощник сохраняет напрямую. **«По умолчанию»** возвращает загрузки через браузер. Выбор сохраняется между перезапусками; смена папки доступна после остановки записи и завершения сохранения. Старые аудиофайлы не перемещаются.

Повторная запись и прямое сохранение MP3 проверяются по **точному ID Suno**. Разные генерации с одинаковыми названиями считаются разными треками; MP3 и WAV одного ID — одним треком коллекции. Auto-Grab пропускает уже сохранённый трек и продолжает ждать следующий, показывая «Уже в коллекции». Сначала запускается захват вступления, затем идёт асинхронная проверка; повторная проверка перед обработкой не даёт сохранить дубликат, если предыдущий файл ещё стоял в очереди.

В коллекцию включается только полная запись с начала до естественного конца либо успешно сохранённый CDN-файл. Намеренный ручной фрагмент не препятствует последующей полной записи. Файл проверяется на наличие, размер и время изменения: удалённую или изменённую запись можно записать заново. Переименованный/перемещённый вручную файл нужно привязать снова.

Старые файлы без ID нельзя надёжно узнать по названию. Для них выбери соответствующий трек в Suno и нажми **«Связать с существующим файлом…»** в настройках. Выбирай полный MP3/WAV именно этого ID; помощник проверит наличие аудио и запомнит соответствие, не переписывая файл. Связь сохраняется независимо от выбранной папки вывода.

Настройки и индекс коллекции находятся в `%LOCALAPPDATA%\SunoBeast`. При загрузке через браузер трек считается сохранённым только после завершения загрузки и проверки полученного файла. При отмене готовое аудио остаётся в `SunoBeast\pending`, путь показывается в сообщении; отменённая загрузка не блокирует повтор. Для передачи готового файла в браузер действует лимит 512 МБ; более крупный результат остаётся у помощника с указанием пути. Повторные запросы из нескольких помощников защищены резервированием ID на время сохранения. База не сканирует произвольные папки и не угадывает соответствия по названиям.

## Индикация воспроизведения — версия 2.4.0

Карточка показывает название, исполнителя, обложку, доступный альбом, текущую позицию и общую длительность (`1:12 / 3:47`). Полоса прогресса — нативный индикатор `<progress>`, без перемотки, ползунка, кнопок паузы или переключения треков. Обновление показаний не меняет воспроизведение в Suno. Статусы различают воспроизведение, паузу, завершение и перемотку, выполненную в самом Suno.

Расширение читает публичные `navigator.mediaSession.metadata` в изолированном контексте и время текущего `<audio>`. Название/обложка плеера остаются запасным источником. Запоздавшие медиаданные другой генерации отбрасываются по названию и ID в обложке, когда он присутствует. Альбом скрыт, если Suno передаёт пустую строку; название плейлиста или исполнителя не подставляется вместо него. Переданный альбом также встраивается в новые MP3.

Панель получает локальные показания каждые 500 мс, отдельно от проверки помощника раз в 5 секунд. Обработка FFmpeg и загрузка метаданных не задерживают часы. При смене трека позиция берётся из нового снимка плеера, а отсутствующие время/длительность отображаются как `—:—`. Сведения доступны и без активной записи. Время показывает позицию воспроизведения в Suno, а не длительность вручную записанного фрагмента.

При проверке на открытой вкладке Suno подтверждены название, автор, обложка и доступ из изолированного контекста; поле альбома у выбранного трека было пустым. Для проверки новой панели обнови установленное расширение и открой его в Suno. Основание API: [Media Session — W3C explainer](https://github.com/w3c/mediasession/blob/main/explainer.md).

## Обложка, стиль и текст — версия 2.2.0

В карточке текущего трека отображаются настоящая обложка Suno, автор, длительность и модель, а ниже — краткий стиль. Блок «Стиль и текст» раскрывает полный стиль и текст песни. Кнопка «Обновить сведения» запрашивает их повторно; ссылка рядом открывает исходную карточку Suno.

Сведения извлекаются из данных HTML страницы `https://suno.com/song/<id>` без скачивания аудио, чтения cookies и копирования авторизационных токенов. Встроенные скрипты страницы не выполняются: разбираются JSON и текстовые записи React Flight, включая полный текст на Unicode. Запрос идёт в фоне и не блокирует запись следующего трека. Данные сопоставляются по точному ID песни, кешируются на 15 минут и не переносятся на соседний трек при запоздавшем ответе.

Если карточка приватна или Suno не возвращает сведения, расширение показывает доступные название/автора/обложку плеера и сообщает, что полные данные недоступны. Отсутствующий текст не заменяется выдуманным. Визуальный запасной вариант для отсутствующей/недоступной картинки — иконка ноты.

Для MP3 обложка встраивается как attached picture, стиль — в genre, полный текст — в lyrics/comment; также сохраняются модель и ссылка на источник. Для WAV записываются поддерживаемые поля title/artist/genre/comment, обложка в WAV не встраивается. Если обложка недоступна или повреждена, аудио сохраняется без неё. Запросы изображений разрешены только к HTTPS CDN Suno, с повторной проверкой каждого redirect и лимитом 5 МБ.

Новые метаданные добавляются к новым записям; старые файлы автоматически не переписываются. После обновления версии перезапусти расширение и открой его панель в Suno, чтобы подключились новые скрипты.

Обработка идёт после завершения трека. Во время обработки запись следующего трека продолжается; панель показывает оба процесса. Лимит записи и суммарной очереди сохранения — 256 МБ исходного WebM. Захватывается весь звук вкладки, включая другие звуки, воспроизведённые сайтом во время записи. Явная кнопка «Остановить» в ручном режиме сохраняет намеренно записанный фрагмент; остановка воспроизведения в самом Suno отбрасывает незавершённую запись.

У CDN-файла MP3 с отключённой обрезкой аудиопакеты копируются без перекодирования. Запись вкладки использует WebM Opus с последующим преобразованием: это не студийный lossless-оригинал. WAV из такой записи также не восстанавливает качество исходника.

При ошибке FFmpeg исходник сохраняется как `Recovery_*.webm` в выбранной папке, а в режиме браузерных загрузок — в `%LOCALAPPDATA%\SunoBeast\recovery`; путь указывается в ошибке. При ошибке передачи помощнику расширение пытается сохранить резервный WebM в стандартных загрузках браузера, подкаталог `Suno Beast`. При закрытии браузера до остановки записи данные, остающиеся в памяти рекордера, могут быть потеряны.

## Локальный помощник

Требуются установленные Node.js и FFmpeg в `PATH`. При переносе проекта или повторной настройке запусти из каталога проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-extension.ps1
```

Установщик регистрирует только текущему пользователю Native Messaging host `com.sunobeast.audio` для Chrome и Edge. Администраторские права и сетевой сервер не требуются. Разрешён один ID расширения: `pkcnkgcepdcheeadhfhbddncimmndmlf`.

Папка вывода меняется в панели расширения. Старый `downloads/suno_settings.json` больше не задаёт папку для расширения; он относится к прежнему Electron-интерфейсу. Настройки расширения и коллекция хранятся отдельно от аудиофайлов.

При ошибке «Помощник не подключён» повтори регистрацию, проверь `node --version` и `ffmpeg -version`, затем перезагрузи расширение. После перемещения проекта требуется повторная регистрация. Для удаления регистрации помощника есть `uninstall-helper.ps1`; записи и профили браузера сохраняются.

## Доступы

В 2.4.3 панель получила мягкое округлое обрамление и неподвижную шапку, но оставалась внутри прямоугольного окна браузера. С 2.5.0 этот способ показа заменён плавающей панелью внутри страницы Suno: за её скруглёнными углами видна сама страница, отдельной прямоугольной подложки и браузерной рамки нет. Кнопка расширения в Suno открывает/закрывает панель; крестик и Escape закрывают только интерфейс. Запись и Auto-Grab продолжаются в offscreen-документе. На других сайтах кнопка открывает Suno.

Панель закреплена в правом верхнем углу и остаётся открытой при работе с Suno. Высота ограничена 600 px и размером вкладки, ширина — 400 px. Видимая вертикальная полоса прокрутки убрана; содержимое по-прежнему прокручивается колёсиком, тачпадом и клавиатурой. Для клавиатуры область содержимого доступна через Tab, далее работают Page Down/End; настройки и папка записей остаются доступны ниже. Индикатор времени сохранён и по-прежнему не позволяет перематывать.

Оформление находится в закрытом Shadow DOM, интерфейс — в iframe с origin расширения; стили и код Suno с ним не смешиваются. Через `web_accessible_resources` только `popup.html` разрешён для двух точных origin Suno. Команды панели принимаются лишь от созданной расширением сессии с точным URL, ID вкладки и привязкой к frame/document. Страница Suno по-прежнему не может вызывать команды помощника. Закрытие панели не вызывает команды остановки записи. Основания: [Chrome — action и обработчик нажатия](https://developer.chrome.com/docs/extensions/reference/api/action), [Chrome — доступные странице ресурсы](https://developer.chrome.com/docs/extensions/reference/manifest/web-accessible-resources), [исходник стандартного popup Chromium](https://raw.githubusercontent.com/chromium/chromium/main/chrome/browser/ui/views/extensions/extension_popup.cc).

Панель 2.1.1 оформлена по визуальному образцу Suno: тёмные нейтральные поверхности, светлая основная кнопка, округлые элементы и локальная копия SVG логотипа с сайта. Логотип используется рядом с отдельной меткой Beast. Источник указан в `extension/assets/README.md`. Дизайн не требует загрузки шрифтов или графики с внешних серверов.

Расширение использует Manifest V3. Скрипт содержимого включён только для `https://suno.com` и `https://www.suno.com`. Разрешения на `*.suno.ai` и `*.suno.com` нужны для обнаружения CDN-запросов. Доступов к Google, cookies, истории браузера и паролям нет.

`tabCapture` захватывает вкладку после действия пользователя. `scripting` восстанавливает скрипт только в открытой вкладке Suno после проверки URL и отсутствующего ответа. `offscreen` сохраняет запись при закрытии панели. `nativeMessaging` передаёт аудио локальному помощнику. `downloads` сохраняет готовое аудио в папку браузера и резервный WebM при сбое помощника. `storage` хранит настройки. Код не меняет User-Agent, TLS, сертификаты или защиту Google.

Помощник проверяет origin расширения, команды, размеры сообщений и файлов. Для загрузки разрешены только HTTPS-адреса аудио Suno; каждый redirect проверяется повторно. FFmpeg не разрешены сетевые протоколы при чтении записанного аудио.

## Проверки

```powershell
npm test
```

Тесты требуют FFmpeg и ffprobe. Проверяются Native Messaging и Windows launcher, реальная обрезка и сохранение длительности без обрезки, копирование MP3 без перекодирования, восстановление при ошибке, границы доменов, запрет привилегированных команд от страницы и переходы рекордера. Для 2.3.0 дополнительно проверяются точные ID/одинаковые названия, перезапуск помощника, удаление и изменение файлов, неполные фрагменты, резервирование параллельных сохранений, подтверждение/отмена браузерной загрузки и возврат папки по умолчанию. Системный диалог выбора и окончательный путь реального браузера требуют проверки после перезагрузки установленного расширения.

Пользователь подтвердил установку расширения, реальную запись и разделение треков. Версия 2.1.0 исправляет потерю начала следующего трека: завершение MediaRecorder и сохранение через FFmpeg больше не блокируют захват. Регрессионные тесты намеренно задерживают и старый onstop, и FFmpeg, проверяют независимость буферов/метаданных и отсутствие файлов для прерванного трека. Повторная проверка этой версии в реальном Suno остаётся необходимой: тесты рекордера моделируют API Chrome.

После правки файлов нажми «Обновить» у Suno Beast на странице расширений и открой его панель в Suno. Включи Auto-Grab до начала воспроизведения. Дай двум трекам закончиться естественно, затем останови третий в Suno: первые два должны сохраниться с началом, третий не должен появиться в загрузках. Уже созданные старой версией файлы автоматически не классифицируются и не удаляются.

`start.bat` и `npm start` теперь открывают Suno в системном браузере. Используй Chrome или Edge. Старый Electron-интерфейс доступен через `npm run start:legacy`; для входа Google предназначен вариант с расширением.
