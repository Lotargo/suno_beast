# История изменений

## Не выпущено

### Добавлено

- Полный Windows x64-установщик со встроенными Node.js, FFmpeg и ffprobe. npm и загрузка дополнительных компонентов при установке не требуются.
- Установка в профиль пользователя, регистрация помощника, инструкция подключения расширения и удаление через настройки Windows.
- Проверка встроенных компонентов перед регистрацией, автоматическое переключение прежнего помощника с резервной копией и откатом при ошибке, защита непустых папок, обновление с сохранением записей и коллекции.
- Восстановление прежней регистрации при удалении, если старая копия ещё существует; сохранение более поздних изменений регистрации.
- Лицензии, точные исходники FFmpeg/LAME/zlib и сценарий сборки включены в комплект.

## [2.10.0] — 2026-10-19

### Добавлено

- Поддержка Яндекс Браузера на Windows.
- Экспериментальная совместимость с Opera, Opera GX и Яндекс Браузером на macOS: инструкции загрузки расширения и macOS-регистрация помощника для Яндекс Браузера. Opera, Opera GX и Яндекс Браузер на Windows используют регистрацию Chrome.
- Понятные сообщения на русском и английском, если версия браузера не предоставляет API записи вкладки или фонового документа.
- Проверки конфликта регистрации Яндекс Браузера, удаления только собственных Windows-регистраций и отказа от записи до обращения к помощнику при отсутствии нужных API.

## [2.9.0] — 2026-10-19

### Добавлено

- Поддержка macOS в локальном аудиопомощнике для Chrome и Edge.
- Установка Native Messaging в пользовательские каталоги macOS без прав администратора.
- Исполняемый shell-лаунчер с сохранением пути к Node.js и каталогов FFmpeg/ffprobe для запуска из браузера.
- Системные диалоги выбора папки и существующего аудиофайла через AppleScript, открытие выбранной папки в Finder.
- Проверки регистрации помощника, защиты существующей регистрации и macOS-ветки выбора папки.

### Изменено

- `npm run install:helper` автоматически выбирает установщик Windows или macOS.
- Настройки, индекс коллекции и промежуточные файлы на macOS хранятся в `~/Library/Application Support/SunoBeast`.
- README и руководство разработчика описывают установку, обновление и удаление помощника на обеих платформах.

### Исправлено

- Сгенерированный macOS-лаунчер `native/launch-host.sh` исключён из Git, как и локальные файлы Windows-помощника.
